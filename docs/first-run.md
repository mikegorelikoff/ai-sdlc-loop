# First run

After the canonical [installation and verification](start-here.md), ask the agent to use `ai-sdlc-loop-flow` with a bounded outcome, feature slug, and relevant paths. Explore explains the route without writing files. Review the owning skill and planned writes before Apply or any downstream approval.
