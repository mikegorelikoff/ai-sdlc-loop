# Security policy

## Supported versions

Security fixes are provided for the latest tagged release.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not include live credentials, private repository content, or personal data. Include a minimal synthetic reproducer, affected version, impact, and suggested remediation when available.

## Trust model

Approval receipts are local records of an explicit decision, not cryptographic identity proofs. Review the current fingerprint before approval. Loop never authorizes itself, and runtime commands do not use a shell. Keep `.ai-sdlc-loop/` out of version control unless an organizational policy explicitly governs retained evidence.
