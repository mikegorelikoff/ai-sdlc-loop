# Compile evidence context

## Entry

Manifest prerequisites and the selected StepCard are satisfied.

## Procedure

Use only source snapshots, trace IDs and applicable dimensions from prepare. Expand via targeted references when a hypothesis requires resolution. For blind concerns, include requirements, design, tests and relevant operations; missing roles remain UNKNOWN.

Read [execution](../references/execution.md) and use `scripts/hunt.py`.

## Exit

Return validated evidence or an explicit blocker; no lifecycle authority changes.

Record the paths deliberately excluded from this scope. Expand only the sources needed to resolve a specific candidate, and regenerate its snapshot after changing the inventory.
