# Signoff

## Entry

Inspect the QA artifact together with current verification evidence.

## Procedure

Mark `ready` only when every required acceptance scenario has evidence and required manual checks are complete. Otherwise use `planned`, `partial`, or `blocked`, name residual risks, and route command execution to `ai-sdlc-loop-validation` or the lifecycle result to `ai-sdlc-loop-verify`.

## Exit

Return an evidence-backed status, remaining risks, and one next required owner/action.
