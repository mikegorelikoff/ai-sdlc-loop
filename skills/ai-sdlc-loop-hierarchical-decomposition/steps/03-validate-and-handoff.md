# Validate — ai-sdlc-loop-hierarchical-decomposition

## Entry

The manifest prerequisites are satisfied and this owning node is selected.

## Procedure

Run `verify --root <project> --input <decomposition.toon>`; it validates current
source bytes and recomputes the complete report rather than trusting saved status.
Check parent coverage, traceability, supported scope, overlap, deliverability,
granularity, testability and dependency integrity. Deterministic checks enforce
structure; the four reviewers own semantic validity and exhaustive source coverage.

Require meaningful Story INVEST, observable Given/When/Then criteria and a
verification approach. Commands in evidence remain inert. Confirm real dependencies
are exposed, not disguised as failed independence. NFR non-applicability requires
cited evidence and Architecture review. No arbitrary numeric quality scores.

A blocked branch stays blocked. An unrelated reviewed branch can be handed off
only when its own ancestry and prerequisite gates permit it. At the third failed
candidate stop with failed gates and owner questions. Completion means producing a
validated report and explicit next action, never claiming implementation readiness
for unresolved branches.

## Exit

Return the declared evidence or explicit blocker; do not improvise authority.
