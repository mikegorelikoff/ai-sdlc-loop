# Identify

## Entry

Identify the proposed release, exact commit, supported hosts, and required approvals.

## Procedure

Reject moving or ambiguous identities. Read `references/quality-bar.md` and enumerate every required release gate before evaluating results.

## Execution contract

Evaluate an immutable release candidate and its gates; do not publish or approve the release.

Read the [shared execution decisions](../../ai-sdlc-loop-shared-runtime/references/execution-contract.md) once for this invocation.
Apply its required/discoverable/inherited/optional input rules to this step's
declared inputs. Record the source and status of material facts, then validate
the owning output contract and current evidence before completion.

## Exit

Return one immutable candidate identity and gate inventory.
