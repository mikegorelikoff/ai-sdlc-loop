# Handoff

## Entry

Enter after readiness validation.

## Procedure

Name the decision, candidate commit, blockers, risks, owner, and one next action. Never create a tag, release, deployment, or approval from this skill.

## Exit

Return the evidence-backed release handoff.

## Chat presentation

Present the result using the owning `SKILL.md` Chat Output Contract and local [chat schema](../references/chat-output.toon). The machine handoff remains native; show its decision, evidence and owned action without dumping the journal.
